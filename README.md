## 📝 How to Edit Your Portfolio from GitHub

To update your portfolio anytime directly from GitHub:

1. Go to your repository: [github.com/ashikulislamkhan/portfolio](https://github.com/ashikulislamkhan/portfolio)
2. Click on the file **`portfolio-data.js`**.
3. Click the **Pencil icon** (Edit this file) or press the `.` key on your keyboard to open the GitHub web editor.
4. Modify or add whatever you want:
   - **Update Contact Info or Bio**: Modify `profile: { ... }`.
   - **Add New Work Experience**: Add a new entry to `workExperience: [ ... ]`.
   - **Add a New Research Paper**: Add a new entry to `researchWorks: [ ... ]`.
   - **Add an App or Project**: Add a new entry to `projects: [ ... ]`.
   - **Add Certifications or Volunteering**: Update `certifications` or `volunteering`.
5. Scroll down, click **"Commit changes..."**, and confirm.
6. GitHub Pages will automatically deploy your updates live within 30–60 seconds!
